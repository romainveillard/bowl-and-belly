# Bowl & Belly brand assets

Source artwork. The icons the app ships are exported from these into `src/client/public/`, which is the only copy of them.

| File | Use |
| --- | --- |
| `favicon.svg` | Browser tab favicon (simplified mark: the cat alone over the bowl), shipped as is; source of `favicon-16.png` |
| `icon.svg` | Full app icon; source of `favicon-32.png`, `icon-192.png`, `icon-512.png` (manifest, `purpose: "any"`) and `apple-touch-icon.png` (iOS home screen, 180 px) |
| `icon-maskable.svg` | Source of `icon-maskable-512.png` (manifest, `purpose: "maskable"`; artwork inside the 80% safe zone) |
| `icon-light.svg` | Concept F app icon on cream, kept as an alternative for a future dark mode |
| `readme-banner.svg`, `readme-banner.png` | README header (2× PNG; the SVG has text as outlines, so no font needed) |

Colours: ink `#1F2A44`, bowl `#F08A4B`, rim `#CE7741`, cat `#FFC9A3`, rabbit `#F6D4BB`, dog `#F2B48A` / ears `#D99A70`.
Wordmark: Outfit SemiBold. UI: Inter.
